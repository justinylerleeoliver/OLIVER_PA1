# OLIVER_PA1
## Learning Outcomes
The experiment is designed to develop the ability to:
Use basic Python functions, operators, and string operations.
Manipulate strings using indexing, slicing, and built-in string methods.
Apply sequence unpacking to manipulate list elements.
Construct simple Python functions that return specified results.
## Problems Covered

# A. Word Rotation Problem
Create a function named:
**rotate_word(text)**
The required function moves the first character of a non-empty string to the end while preserving the order and capitalization of the remaining characters.

# B. Username Builder Problem
Create a function named:
**make_username(first_name, last_name)**
The function:
Converts the first and last names to lowercase.
Removes spaces from both names.
Combines them using one period (.).

# C. Bookend Swap Problem
Create a function named:
swap_bookends(items)
The function uses extended sequence unpacking:
first, *middle, last = items
It then returns a new list with the first and last elements exchanged while preserving the order of the middle elements.
